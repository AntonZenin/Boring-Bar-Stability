# D-разбиение для крутильных колебаний расточной борштанги

Программа для исследования устойчивости состояния равновесия расточной
борштанги при возбуждении крутильных колебаний методом D-разбиения по
одному комплексному параметру $\hat\delta$.

## Структура проекта

```
BoringBarStability/
├── cpp/
│   ├── CMakeLists.txt          ← конфигурация сборки
│   └── src/
│       └── dpartition.cpp      ← ядро расчёта на C++
├── python/
│   └── gui/
│       ├── gui.py              ← графический интерфейс (Tkinter)
│       └── dpartition.exe      ← собирается сюда автоматически
├── build/                      ← временные файлы CMake (gitignored)
└── README.md
```

## Архитектура

- **`cpp/src/dpartition.cpp`** — расчётное ядро на C++. Принимает все
  физические параметры через командную строку, печатает в stdout
  тройки `omega Re(δ̂) Im(δ̂)` — по одной точке на строку.
- **`python/gui/gui.py`** — графический интерфейс на Tkinter +
  matplotlib. Запускает `dpartition.exe` как подпроцесс, парсит вывод,
  строит кривую D-разбиения с подписями осей `Re δ̂`, `Im δ̂`,
  отмечает точку пересечения с Re-осью. Опционально рисует штрихи
  D-разбиения.

- **MSVC** (Visual Studio Build Tools 2022 с компонентом

- **CMake** ≥ 3.15.

  в стандартную поставку Python для Windows.

Установка Python-зависимостей:

```powershell

```

## Управление

- **Построить** — запустить расчёт с текущими параметрами.
- **Сбросить** — вернуть все поля к значениям по умолчанию.
- **Очистить график** — стереть всё нарисованное.
- **Накладывать кривые (для сравнения)** — если включено, новые
  кривые рисуются поверх старых разными цветами. Удобно сравнивать
  кривые при разных значениях `L` или `δ₁` (исследование влияния
  параметров на область устойчивости — основная цель работы).
- **Показывать штрихи D-разбиения** — рисует короткие
  перпендикулярные чёрточки на кривой, как на рис. 4 отчёта. По
  умолчанию выключено для чистоты графика.

## Реализация формулы

Используется уравнение кривой D-разбиения из отчёта (формула 10):

$$
\hat\delta(p) = -p - \lambda_1 \sqrt{1 + \delta_1\,p}\,
\coth\!\left(\frac{\lambda_2\, p}{\sqrt{1 + \delta_1\,p}}\right),
\qquad p = i\omega
$$

где

$$
\lambda_1 = \frac{\sqrt{\rho\,G\,J_p}}{J_r},\quad
\lambda_2 = L\sqrt{\frac{\rho}{G}},\quad
J_p = \frac{\pi}{2}\bigl(R^4 - r^4\bigr).
$$

Сканирование `ω` идёт от `ω_min` до `ω_max` равномерно в `N` точках;
точка `ω = 0` пропускается, чтобы избежать особенности `coth(0)`.

### Численные тонкости

- **Устойчивое `coth(z)`** для комплексного аргумента вычисляется как
  `1 / tanh(z)`. Прямая формула `cosh(z)/sinh(z)` переполняется при
  больших `Re(z)`, тогда как `std::tanh` из `<complex>` реализован
  устойчиво.
- **Резонансные точки.** На частотах, где
  `λ₂·ω / √(1+δ₁·i·ω) ≈ π·k`, `sinh` обращается в ноль и `coth`
  имеет полюс. В этих точках δ̂ улетает в бесконечность, поэтому в
  Python применяется фильтр `|δ̂| < 50·median(|δ̂|)`, отбрасывающий
  только эти аномалии без потери самой кривой.
