# Boring Bar Stability

Программа для исследования устойчивости состояния равновесия системы,
описывающей крутильные колебания расточной борштанги, методом D-разбиения.

Вычислительное ядро написано на **C++** для скорости, графический интерфейс —
на **Python (PyQt5)**. Связь между языками реализована через **pybind11**.

## Архитектура

```
BoringBarStability/
├── cpp/                  # C++ ядро (вычисления D-разбиения)
│   ├── CMakeLists.txt
│   └── src/
│       └── bindings.cpp  # pybind11 обёртка
├── python/               # Python GUI (PyQt5)
│   └── main.py
├── build/                # сборочные артефакты (не в репозитории)
└── .vscode/              # настройки VS Code
```

После сборки скомпилированный модуль `boring_bar_core.cp3XX-win_amd64.pyd`
помещается в папку `python/` и импортируется как обычный Python-модуль.

## Требования

- Windows 10/11 (x64)
- Visual Studio 2022 с компонентом "Desktop development with C++"
- Python 3.10+ (тестировалось на 3.12)
- CMake 3.15+

## Установка зависимостей Python

```powershell
pip install pybind11 PyQt5 matplotlib numpy
```

## Сборка C++ модуля

Из корня проекта:

```powershell
cd build
cmake -G "Visual Studio 17 2022" -A x64 ..\cpp
cmake --build . --config Release
```

После успешной сборки в папке `python/` появится файл `boring_bar_core.cp3XX-win_amd64.pyd`.

## Запуск

```powershell
cd python
python main.py
```

## Математическая модель

Программа строит кривую D-разбиения по комплексному параметру δ̂
по формуле:

```
δ̂ = -p - λ₁ √(1 + δ₁ p) · coth( λ₂ · p / √(1 + δ₁ p) ),    p = i ω

где   λ₁ = √(ρ G Jₚ) / Jᵣ,   λ₂ = L · √(ρ / G).
```

Параметры:
- `ρ`  — плотность материала борштанги
- `G`  — модуль сдвига
- `Jₚ` — полярный момент инерции сечения
- `Jᵣ` — момент инерции груза на конце
- `L`  — длина борштанги
- `δ₁` — параметр демпфирования
- `ω`  — частота (изменяется в заданном диапазоне)
